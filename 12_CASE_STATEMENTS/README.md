# Day 12 - CASE Statements in MySQL

## 📚 Overview

Today, I learned how to use **CASE Statements** in MySQL.

A CASE statement allows us to add conditional logic to SQL queries, similar to **if-else statements** in programming languages. It evaluates conditions in order and returns a value when a condition is met.

---

## 🧠 Topics Covered

- CASE Statement
- WHEN
- THEN
- ELSE
- END
- Multiple Conditions
- CASE with Numeric Values
- CASE with Text Values
- CASE with JOIN
- CASE with ORDER BY

---

## 📝 What I Learned

- CASE statements allow conditional logic inside SQL queries.
- `WHEN` specifies a condition to evaluate.
- `THEN` defines the value returned when the condition is true.
- `ELSE` provides a default value if no conditions match.
- Every CASE statement must end with `END`.
- CASE statements can classify data into meaningful categories.
- CASE can be combined with JOINs, aliases, filtering, and sorting.
