# Day 17 - Stored Procedures in MySQL

## 📚 Concepts Learned

Today I learned about Stored Procedures in MySQL.

A Stored Procedure is a reusable block of SQL statements that is stored in the database. It can be executed multiple times without rewriting the SQL code, making queries more efficient and easier to maintain.

## Key Takeaways

- Stored Procedures help avoid writing the same SQL repeatedly.
- They improve code reusability and readability.
- Parameters allow dynamic input values.
- They are useful for reports, dashboards, and business logic in real-world databases.
