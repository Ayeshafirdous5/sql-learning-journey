---

## 📝 What I Learned

- UNION combines the results of two or more SELECT statements.
- Both SELECT statements must return the same number of columns.
- The data types of corresponding columns should be compatible.
- UNION removes duplicate rows automatically.
- UNION ALL returns all rows, including duplicates.
- ORDER BY can be used at the end of the UNION query to sort the final result.
- Aliases can be used to make the output more readable.
