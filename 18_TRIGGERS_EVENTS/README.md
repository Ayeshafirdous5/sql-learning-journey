# Day 18 - Triggers & Events in MySQL

## 📚 Concepts Learned

Today I learned about **Triggers** and **Events** in MySQL.

Triggers are automatically executed when a specific database event occurs, such as inserting, updating, or deleting data. Events allow SQL tasks to run automatically on a scheduled basis, making database maintenance and automation much easier.

## Key Takeaways

- Triggers execute automatically when a specified database event occurs.
- The `NEW` keyword accesses values from newly inserted rows.
- Events automate repetitive SQL tasks based on a schedule.
- Triggers and Events are useful for maintaining data integrity, logging changes, and automating routine database operations.
