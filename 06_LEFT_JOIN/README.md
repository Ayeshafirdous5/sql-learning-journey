# Day 6 - LEFT JOIN

## 📚 Overview

Today, I learned **LEFT JOIN** in MySQL.

A LEFT JOIN returns **all rows from the left table** and only the matching rows from the right table. If there is no matching record in the right table, SQL returns **NULL** for those columns.

- Difference between INNER JOIN and LEFT JOIN

- Combining LEFT JOIN with `WHERE` and `ORDER BY`

## 🚀 Key Takeaway

LEFT JOIN is useful when we want to retrieve **all records from the left table**, even if there is no related record in the right table. It is commonly used in reporting and data analysis to identify missing or unmatched data.
