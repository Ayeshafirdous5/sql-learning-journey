# Day 16 - Temporary Tables in MySQL

## 📚 Concepts Learned

Today I learned about Temporary Tables in MySQL.

A Temporary Table is a table that exists only for the current database session. It is commonly used to store intermediate results, simplify complex queries, and improve query readability.

## Key Takeaways

- Temporary Tables exist only during the current SQL session.
- They are automatically removed when the session ends.
- They are useful for storing intermediate query results without affecting permanent database tables.
- Temporary Tables make complex SQL queries easier to organize and understand.
