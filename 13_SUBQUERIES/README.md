# Day 13 - Subqueries in MySQL

## 📚 Overview

Today, I learned about **Subqueries** in MySQL.

A subquery is a query nested inside another SQL query. It allows one query to use the result of another query, making it easier to solve complex problems without writing multiple separate queries.

---

## 📝 What I Learned

- A subquery is executed before the outer query.
- Subqueries can be placed inside the `WHERE`, `SELECT`, and `FROM` clauses.
- The `IN` operator is commonly used with subqueries to compare multiple values.
- Aggregate functions such as `AVG()`, `MAX()`, and `MIN()` can be used within subqueries.
- Nested subqueries make it possible to retrieve data based on multiple levels of conditions.
- Subqueries are useful for filtering, reporting, and analytical queries.
