# Day 15 - Common Table Expressions (CTEs)

## 📚 Concepts Learned

Today I learned about Common Table Expressions (CTEs) in MySQL.

A Common Table Expression (CTE) is a temporary named result set created using the `WITH` clause. It helps simplify complex SQL queries by breaking them into smaller, more readable parts.
