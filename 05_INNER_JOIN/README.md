# Day 5 - INNER JOIN

## 📚 Overview

Today, I learned one of the most important SQL concepts: **INNER JOIN**.

INNER JOIN allows us to combine data from two or more tables using a common column. It returns only the rows where matching values exist in both tables.

To practice JOIN operations, I created a new **company_db** database containing multiple related tables.

---

## 🧠 What I Learned

- Understanding relational databases
- Creating and working with multiple tables
- Using **INNER JOIN** to combine data
- Using aliases (`AS`) to write cleaner SQL queries
- Joining two tables using a common key
- Joining multiple tables in a single query
- Retrieving employee, department, and project information
- Filtering joined data using the `WHERE` clause
- Building simple SQL reports using JOINs
